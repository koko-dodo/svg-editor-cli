# 保存差异标签

从仓库根目录执行 `npm run cli -- --config plugins.star.config.json`，再执行 `init`、编辑命令和 `tree`。配置按 box、modified-star 顺序注册，因此同一行显示 `(box) *`。原 `plugins.config.json` 保留无星号会话；也可以在自定义配置中将本包设为 `enabled: false`。

标签通过公开 TreeDecorator 观察当前文档及最近成功 read/save 的纯值基准，不修改模型或历史。init 后没有保存基准，根和所有节点均标星；read/save 成功后清除，失败保留；撤销或手动编辑回相同内容也清除。内容包括尺寸、语义 kind、ID、父级、属性和有序子树。子树增删、移动、重排或属性变化向祖先传播；移动节点因父级不同而标星；未变的兄弟节点保持无星。根尺寸变化仅使根标星。

实现无状态、无模块级可变状态，也不保留文档引用。属性键顺序和迁移兼容 type 字段不构成内容变化。基准检索及子树比较直接遍历，最坏时间平方级；未进行大文档性能验收。运行无需新增依赖，插件不感知其他标签。
